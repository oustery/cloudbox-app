# 🎨 CloudBox — Анализ дизайна и функций (UI/UX)
*Основано на дизайн-системе Google Material Design 3 (M3) и идеологии мобильных приложений Google.*

В данном документе представлен анализ текущего состояния (на основе описания и планов) и 20 пунктов улучшений для приложения **CloudBox**, направленных на создание современного, интуитивно понятного и эстетичного пользовательского опыта, характерного для таких продуктов как Google Drive, Google Photos и Google Files.

## 📱 Глобальная навигация и структура (Navigation & Structure)

1.  **Bottom Navigation Bar (M3)**
    *   **Рекомендация:** Заменить или внедрить нижнюю панель навигации по стандарту Material 3 с активными индикаторами (pill-shaped).
    *   **Разделы:** "Главная" (Home), "Файлы/Облако" (Cloud/Shared), "Загрузки" (Downloads), "Настройки/Профиль" (Profile).
    *   **Обоснование:** Обеспечивает быстрый доступ к основным функциям приложения одной рукой, что является стандартом для файловых менеджеров Google.

2.  **Edge-to-Edge Design**
    *   **Рекомендация:** Реализовать поддержку edge-to-edge (контент заходит под прозрачные статус-бар и навигационную панель устройства).
    *   **Обоснование:** Делает интерфейс более глубоким и современным, максимизируя полезную площадь экрана при просмотре медиа.

3.  **Dynamic Color (Material You)**
    *   **Рекомендация:** Интегрировать поддержку динамических цветов на основе обоев пользователя (Android 12+).
    *   **Обоснование:** Глубокая интеграция с системой, приложение ощущается как нативное и персональное.

4.  **Floating Action Button (FAB) для главных действий**
    *   **Рекомендация:** Использовать Extended FAB с иконкой и текстом (например, "Вставить ссылку" или "Добавить папку") на главном экране. При скролле вниз сворачивать в обычный круглый FAB.
    *   **Обоснование:** Привлекает внимание к основному пользовательскому сценарию — добавлению новых ссылок для просмотра.

## 📂 Проводник файлов (Folder Explorer)

5.  **Интерактивные "Хлебные крошки" (Interactive Breadcrumbs)**
    *   **Рекомендация:** Реализовать горизонтально прокручиваемый список чипов (Chips) для навигации по вложенным папкам, как в Google Drive.
    *   **Обоснование:** Позволяет легко вернуться на несколько уровней вверх без многократного нажатия кнопки "Назад".

6.  **Универсальные карточки файлов (M3 Cards)**
    *   **Рекомендация:** Использовать скругленные карточки (Elevated или Filled Cards) для файлов. В режиме списка (List) размещать превью слева, название и метаданные по центру, кнопку меню (три точки) справа.
    *   **Обоснование:** Четкое визуальное разделение элементов, улучшенная читаемость.

7.  **Состояния пустых экранов (Empty States)**
    *   **Рекомендация:** Разработать красивые пустые экраны (когда нет файлов, нет загрузок, нет избранного) с крупной тематической иллюстрацией и призывом к действию (Call to Action).
    *   **Обоснование:** Снижает когнитивную нагрузку и подсказывает пользователю следующий шаг.

8.  **Pull-to-Refresh с M3 индикатором**
    *   **Рекомендация:** Использовать стандартный SwipeRefreshLayout с современным индикатором загрузки (колесо на цветном фоне) для обновления содержимого папки.
    *   **Обоснование:** Привычный паттерн обновления данных.

9.  **Улучшенный Batch Selection (Пакетный выбор)**
    *   **Рекомендация:** При долгом нажатии на файл переходить в режим выделения. Верхняя панель (Top App Bar) должна меняться на контекстную (Contextual Action Bar) с отображением количества выбранных элементов и доступными действиями (Скачать, Удалить из истории).
    *   **Обоснование:** Безопасный и очевидный способ работы с несколькими файлами одновременно.

## 🖼️ Медиагалерея и Плеер (Media Viewing)

10. **Бесшовные переходы (Shared Element Transitions)**
    *   **Рекомендация:** Анимация раскрытия превью изображения из сетки файлов в полноэкранный просмотрщик.
    *   **Обоснование:** Создает плавность интерфейса и пространственное понимание того, откуда открылся файл (паттерн из Google Photos).

11. **Иммерсивный режим (Immersive Mode) для медиа**
    *   **Рекомендация:** При открытии фото или видео скрывать все системные и UI-элементы (App Bar, Bottom Nav) по одиночному тапу по экрану. Фон просмотрщика должен быть строго черным (#000000).
    *   **Обоснование:** Фокусирует внимание на контенте.

12. **Карусель и предзагрузка (Preloading Carousel)**
    *   **Рекомендация:** Использовать Horizontal Pager для перелистывания медиафайлов. Загружать соседние изображения в фоне (прекэширование) для мгновенного свайпа.
    *   **Обоснование:** Устраняет задержки при просмотре больших альбомов.

13. **Modern Video Player UI**
    *   **Рекомендация:** Интерфейс плеера должен повторять паттерны YouTube / ExoPlayer по умолчанию: полупрозрачный градиент снизу и сверху для читаемости контролов, двойной тап по краям для перемотки на 10 секунд.
    *   **Обоснование:** Использование устоявшихся мышечных привычек пользователей Android.

## ⚡ Менеджер загрузок (Download Manager)

14. **Интерактивные уведомления о загрузке**
    *   **Рекомендация:** Использовать системные уведомления с прогресс-баром, отображением скорости и кнопками "Пауза/Отмена" (Actions) прямо в шторке.
    *   **Обоснование:** Позволяет управлять фоновыми задачами без необходимости открывать приложение.

15. **Карточки активных загрузок (Progress Cards)**
    *   **Рекомендация:** В разделе "Загрузки" использовать карточки с линейным индикатором прогресса (LinearProgressIndicator) M3, оценкой оставшегося времени и скорости скачивания.
    *   **Обоснование:** Прозрачность длительных процессов.

16. **Snackbar для быстрых уведомлений**
    *   **Рекомендация:** Использовать Snackbar ("Загрузка завершена", "Ссылка скопирована") с кнопкой действия (например, "ОТКРЫТЬ").
    *   **Обоснование:** Ненавязчивое информирование пользователя об успешных фоновых действиях.

## 🔍 Поиск и ввод данных (Search & Input)

17. **Поле поиска (Search Bar / Search View)**
    *   **Рекомендация:** Использовать M3 SearchBar в верхней части экрана (вместо Top App Bar) или как разворачивающийся элемент. Поддерживать поиск с историей запросов.
    *   **Обоснование:** Быстрый доступ к поиску, как в Google Drive или Gmail.

18. **Интеллектуальная вставка (Smart Paste)**
    *   **Рекомендация:** Если приложение обнаруживает ссылку на Mail.ru в буфере обмена при запуске, предлагать чип (Suggestion Chip) или диалог "Открыть ссылку из буфера обмена?".
    *   **Обоснование:** Сокращает количество кликов для основного сценария использования.

## ⚙️ Взаимодействие и микроанимации

19. **Скелетные экраны (Skeleton Loaders)**
    *   **Рекомендация:** Вместо крутящегося спиннера (CircularProgressIndicator) при первоначальной загрузке списка файлов показывать серые мерцающие блоки (Shimmer Effect), повторяющие структуру списка.
    *   **Обоснование:** Создает иллюзию более быстрой загрузки и подготавливает пользователя к макету страницы.

20. **BottomSheet для свойств и контекстных меню**
    *   **Рекомендация:** При нажатии на меню файла (три точки) или просмотре "Свойств" (EXIF) использовать Modal Bottom Sheet (всплывающую панель снизу) вместо полноэкранных диалогов.
    *   **Обоснование:** Легко дотянуться большим пальцем, не отрывает пользователя от контекста (списка файлов).
