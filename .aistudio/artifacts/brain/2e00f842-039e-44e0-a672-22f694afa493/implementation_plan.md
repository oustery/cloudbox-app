# Облако Mail.ru Viewer & Downloader (CloudBox)

Полнофункциональное Android-приложение для сохранения публичных ссылок Облака Mail.ru (`cloud.mail.ru/public/...`), навигации по папкам, мгновенного предпросмотра изображений, встроенного воспроизведения видео, полноразмерного просмотра медиафайлов с жестами зума и надежного менеджера фоновых загрузок в системное хранилище.

---

### Подтвержденные решения пользователя (Фаза 1)

- **Медиаплеер и просмотр**: Встроенный полноэкранный видеоплеер с поддержкой перемотки/пауз и галерея изображений с pinch-to-zoom жестами и горизонтальным свайпом между файлами в папке.
- **Система загрузки**: Встроенный диспетчер загрузок (Download Manager) с отображением прогресса, скорости, размера, статусов (в очереди, пауза, загружено, ошибка) и сохранением в публичный каталог `Downloads` устройства.
- **Организация ссылок**: Библиотека сохраненных ссылок с разделением по категориям, тегами, избранным, предпросмотром количества элементов и времени добавления.

---

## 1. Деконструкция и реверс-инжиниринг протокола Cloud Mail.ru

Публичные ссылки Облака Mail.ru имеют типовой вид:  
`https://cloud.mail.ru/public/{key_part_1}/{key_part_2}` (например, `https://cloud.mail.ru/public/KVy7/S1hRRPVUE`).

### Архитектура публичного API Mail.ru Cloud

1. **Нормализация и извлечение ключа (Weblink Key)**:
   - Вход: `https://cloud.mail.ru/public/KVy7/S1hRRPVUE` или короткие варианты.
   - Weblink: `KVy7/S1hRRPVUE`.
   - Вложенные пути: `KVy7/S1hRRPVUE/Photos/Summer2024/img.jpg`.

2. **Диспетчеризация серверов (Dispatcher Shards API)**:
   - Запрос: `GET https://cloud.mail.ru/api/v2/dispatcher`
   - Ответ возвращает список актуальных пулов серверов (shards) с балансировкой нагрузки:
     - `weblink_get`: `[{ "url": "https://clocloXX.cloud.mail.ru/weblink/get/" }]` — базовый URL прямого скачивания.
     - `weblink_thumbnails`: `[{ "url": "https://thumb.cloud.mail.ru/weblink/thumb/" }]` — генератор превью любого размера (например, `/thumb/256/` или `/thumb/1024/`).
     - `weblink_view`: `[{ "url": "https://clocloXX.cloud.mail.ru/weblink/view/" }]` — потоковый просмотр видео/аудио.

3. **Листинг содержимого папок (Folder Listing API)**:
   - Запрос: `GET https://cloud.mail.ru/api/v2/folder?weblink={weblink_key}&offset=0&limit=1000`
   - Заголовки: стандартный `User-Agent` современного мобильного браузера.
   - Структура ответа (`body.list`):
     - `kind`: `"folder"` или `"file"`
     - `name`: имя файла/папки
     - `size`: размер в байтах
     - `type`: `"image"`, `"video"`, `"audio"`, `"document"`, `"archive"`
     - `mtime`: unix timestamp модификации
     - `weblink`: относительный ключ ресурса для скачивания
     - `count.folders`, `count.files`: для папок

4. **Генерация прямых URL для скачивания и стриминга**:
   - Скачивание файла: `{weblink_get_url}{item_weblink}` (с автоматическим следованием редиректам OkHttp).
   - Превью изображения: `https://thumb.cloud.mail.ru/weblink/thumb/512/{item_weblink}`.
   - Потоковое воспроизведение видео: `{weblink_view_url}{item_weblink}` или прямое чтение с поддержкой `Range: bytes=...`.

5. **Fallback-механизм (Web Scraping Fallback)**:
   - Если API возвращает ограничение или специфический формат ссылки, парсится HTML-страница `https://cloud.mail.ru/public/...`, извлекающая внедренный в теги `<script>` объект состояния с конфигурацией пула и прямой ссылкой.

## 2. Пользовательский интерфейс и дизайн (Jetpack Compose M3)

### Эстетика и стиль
- **Тема**: Высокотехнологичный глубокий интерфейс (Deep Cloud & Cobalt Navy) в стиле современного Material 3.
  - Первичный акцент: `#0077FF` (фирменный синий оттенок облачных сервисов) в комбинации с динамическим аквамариновым `#00E5FF`.
  - Фон в темной теме: `#0F141C` (глубокий полуночный синий) с карточками `#1A2230` и акцентными обводками `#2A364F`.
  - Типографика: четкая иерархия с четкими размерами файлов, моноширинными бейджами расширений (`.MP4`, `.RAW`, `.ZIP`, `.JPG`).

### Ключевые экраны и сценарии (Flows)

1. **Главный экран (Библиотека ссылок & Ввод)**:
   - Верхняя карточка быстрого ввода: вставка ссылки из буфера обмена одной кнопкой с автоматической валидацией формата `cloud.mail.ru/public/...`.
   - Быстрые фильтры / Категории: «Все», «Фото и видео», «Документы», «Архивы», «Избранное».
   - Список сохраненных публичных ресурсов с превью первой картинки, именем папки/файла, количеством файлов и кнопками быстрого действия (Открыть, Поделиться, Удалить).

2. **Экран проводника облачной папки (Folder Explorer)**:
   - Навигационный хлебный мякиш (Breadcrumbs) для перехода по подпапкам.
   - Режимы отображения: адаптивная сетка (Grid) для медиафайлов и детальный список (List) с размерами и датами.
   - Поиск и сортировка (по имени, размеру, дате, типу).
   - Кнопка массового выделения (Select All / Batch Download) для быстрой загрузки всей папки или выбранных файлов.

3. **Встроенная полноэкранная медиагалерея (Photo Viewer)**:
   - Интерактивный просмотрщик с жестами Pinch-to-Zoom, двойным тапом для приближения до 100%/300% и панорамированием (Pan).
   - Горизонтальный пейджер (`HorizontalPager`) для быстрого листания фото в текущей папке.
   - Оверлей с метаданными (разрешение, размер, имя) и быстрыми кнопками: «Скачать в галерею», «Поделиться».

4. **Встроенный видеоплеер (Video Player)**:
   - Полноэкранный плеер с адаптивными элементами управления (Play/Pause, слайдер перемотки, таймкоды, блокировка экрана, соотношение сторон).
   - Буферизация и индикация прогресса загрузки фрагментов.

5. **Менеджер загрузок (Download Hub)**:
   - Вкладки: «Активные», «Завершенные», «Ошибки».
   - Детальная карточка каждой загрузки: линейный анимированный прогресс-бар, скорость в МБ/с, скачанный объем из общего, оставшееся время.
   - Кнопки паузы, возобновления, отмены и открытия скачанного файла в системе.

### Модели данных (Room Entities)

1. `SavedLinkEntity`:
   - `id: Long` (Primary Key)
   - `url: String`
   - `weblinkKey: String` (например `KVy7/S1hRRPVUE`)
   - `title: String`
   - `category: String` (например "Фото", "Видео", "Рабочее", "Избранное")
   - `itemCount: Int`
   - `totalSize: Long`
   - `previewThumbnailUrl: String?`
   - `isFavorite: Boolean`
   - `createdAt: Long`

2. `DownloadTaskEntity`:
   - `id: String` (UUID)
   - `weblink: String`
   - `downloadUrl: String`
   - `fileName: String`
   - `fileSize: Long`
   - `downloadedBytes: Long`
   - `status: DownloadStatus` (`QUEUED`, `DOWNLOADING`, `PAUSED`, `COMPLETED`, `FAILED`)
   - `destinationPath: String`
   - `mimeType: String`
   - `createdAt: Long`

## 4. План реализации по шагам

1. **Сетевой слой и клиент API Cloud Mail.ru**:
   - Добавление `libs.coil.compose` в dependencies для загрузки превью.
   - Реализация Retrofit/OkHttp сервиса `CloudMailRuService`:
     - Эндпоинт `getDispatcher()` -> получение `weblink_get` и `weblink_thumbnails`.
     - Эндпоинт `getFolder(weblink, offset, limit)` -> десериализация списка файлов и папок.
     - Утилита нормализации ссылок (распознавание формата `https://cloud.mail.ru/public/...`, очистка от GET-параметров).
     - Генератор прямых ссылок для скачивания и превью любого размера.

2. **Локальная база данных (Room)**:
   - Описание Entities (`SavedLinkEntity`, `DownloadTaskEntity`).
   - Описание `CloudLinkDao` и `DownloadDao` с `Flow` реактивными запросами.
   - База данных `AppDatabase` с миграцией / initial setup.

3. **Менеджер фоновых загрузок**:
   - Многопоточный сервис/менеджер на корутинах с поддержкой остановки, паузы и возобновления.
   - Стриминг через `ResponseBody.byteStream()` с вычислением скорости (КБ/с, МБ/с) и процента выполнения.
   - Сохранение файлов в `Environment.DIRECTORY_DOWNLOADS` через `MediaStore` / `File API` для немедленной доступности в файловом менеджере и галерее Android.

4. **UI-компоненты просмотра медиа**:
   - Полноэкранный просмотрщик изображений с поддержкой `Modifier.graphicsLayer` (scale, translation, pinch-to-zoom, double-tap zoom).
   - Встроенный медиаплеер с оверлеем управления воспроизведением.

5. **Пользовательский интерфейс**:
   - `HomeScreen`: карточка быстрой вставки ссылки, библиотека категорий, сетка/список папок.
   - `ExplorerScreen`: просмотр файлов в облаке, фильтрация по типу (видео/фото/документы), быстрый выбор и скачивание.
   - `DownloadsScreen`: панель очереди и истории загрузок с кнопками управления.
   - `MediaViewerScreen`: просмотр любого файла на весь экран.

6. **Верификация**:
   - Сборка и компиляция через `compile_applet`.
   - Проверка корректной работы всех сценариев.
