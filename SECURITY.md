# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using [GitHub Security Advisories](https://github.com/oustery/cloudbox-app/security/advisories/new). Do not include exploit details, personal data, access tokens, or credentials in public issues.

Include the affected app version or commit, the Android/API level if applicable, clear reproduction steps, and the impact you observed. The maintainers will coordinate a fix and disclosure through the private advisory.

## Supported versions

Security fixes are applied to the latest development version on `main`. Releases are published through the repository's GitHub Actions pipeline.
