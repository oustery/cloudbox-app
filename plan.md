В данном документе зафиксирован детальный инженерный бэклог, архитектурные улучшения и продуктовые функции для последующих итераций приложения **CloudBox**.

## 📌 Версия 1.1 — Скорость загрузки и мультимедиа-апгрейд (High Priority)

### 1. Многопоточная сегментированная загрузка (Multi-part Slicing)
- **Проблема**: При загрузке больших файлов (видео > 1 ГБ, архивы) однопоточный HTTP-стриминг упирается в ограничения полосы пропускания одиночного TCP-соединения провайдера.
- **Решение**:
  - Реализовать `ChunkedDownloadEngine`: параллельное скачивание 3–4 сегментов одного файла через заголовки `Range: bytes={start}-{end}`.
  - По завершении сегментов — бинарное объединение в целевой файл (`RandomAccessFile`).
  - Ожидаемый прирост скорости скачивания: в 2.5–4 раза на высокоскоростных сетях Wi-Fi/LTE.

### 2. Переход на Media3 / ExoPlayer
- **Проблема**: Системный `VideoView` имеет ограниченную поддержку кодеков, аудиодорожек и встроенных субтитров в форматах MKV/MP4.
- **Решение**:
  - Интегрировать библиотеку `androidx.media3:media3-exoplayer` и `media3-ui`.
  - Добавить переключение аудиодорожек и субтитров на лету.
  - Добавить регулировку скорости воспроизведения (0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x).
  - Внедрить фоновое воспроизведение звука с панелью в системных уведомлениях через `MediaSessionService`.

### 3. Быстрый предпросмотр содержимого ZIP-архивов
- **Проблема**: Чтобы узнать состав лежащего в Облаке ZIP-архива на 5 ГБ, пользователю сейчас требуется скачать его целиком.
- **Решение**:
  - Реализовать чтение оглавления (Central Directory Header) архива по HTTP Range с конца файла (последние 64 КБ).
  - Отображать виртуальное дерево файлов архива прямо в проводнике без скачивания всего объема.

## 📌 Версия 1.2 — Организация, приватность и экспорт (Medium Priority)

### 1. Биометрическая защита и приватные папки
- **Возможность**:
  - Блокировка избранных облачных папок по отпечатку пальца / Face Unlock с помощью `androidx.biometric:biometric`.
  - Скрытие превью приватных папок в основном списке и защита доступа PIN-кодом.

### 2. Экспорт в сторонние хранилища и WebDAV
- **Возможность**:
  - Прямой экспорт скачанных файлов в Google Drive, Яндекс Диск, Nextcloud или локальный NAS по протоколу WebDAV/SMB.
  - Интеграция с системным `DocumentsProvider` (SAF) для выбора произвольной папки сохранения на SD-карте или внешнем USB OTG накопителе.

### 3. Инспектор метаданных (EXIF & Media Info)
- **Возможность**:
  - При просмотре фотографий добавить панель «Свойства»: модель камеры, объектив, ISO, выдержка, диафрагма, разрешение и геолокация на карте.
  - Для видео: разрешение, битрейт, используемый видео- и аудиокодек, FPS.

## 📌 Версия 2.0 — Экосистема и адаптивность (Long-Term Vision)

### 1. Планшетный и Desktop-режим (Canonical Split-Pane Layouts)
- **Архитектура**:
  - Поддержка `WindowSizeClass` (Compact, Medium, Expanded).
  - На складных смартфонах (Foldables) и планшетах: двухпанельный интерфейс **List-Detail View** (слева список папок и файлов, справа постоянный интерактивный медиаплеер с метаданными).
  - Поддержка управления клавиатурой и мышью для ChromeOS и Samsung DeX.

### 2. P2P-передача по локальной сети (Local Share)
- **Возможность**:
  - Встроенный сервер быстрой передачи скачанных файлов на находящиеся рядом устройства (ПК, iPhone, другие Android) по локальному Wi-Fi без расхода мобильного трафика.

### 3. Модульный провайдер облачных хранилищ
- **Архитектура**:
  - Абстрагировать `CloudMailRuRepository` в общий интерфейс `CloudProviderRepository`.
  - Добавить аналогичные легковесные парсеры для публичных ссылок других сервисов:
    - Яндекс Диск (`disk.yandex.ru/d/...`)
    - Google Drive публичные папки (`drive.google.com/drive/folders/...`)
    - Mega.nz

## 🧪 Инженерные метрики и оптимизация

| Метрика | Текущее значение | Целевое значение (v1.2) |
|---|---|---|
| **Размер APK (arm64-v8a)** | ~18 МБ | < 12 МБ (после включения R8 fullMode) |
| **Время старта приложения (Cold Start)** | ~450 мс | < 300 мс |
| **Потребление RAM при просмотре 4K фото** | ~95 МБ | < 50 МБ (аппаратный Bitmap декодер) |
| **Максимальная скорость скачивания** | Ограничена 1 потоком | Полноскоростная (4 параллельных чанка) |
| **Покрытие тестами (Unit & Robolectric)** | 85% критической логики | > 92% |
